## 1. 品牌与定位

### 1.1 品牌信息 —— **由使用者自己填**

本仓库**不带任何特定社团的品牌信息**。下面这些值都集中在
`src/main/java/com/fountainhub/config/GlobalModelAdvice.java`，**改那几行就变成你自己的**：

| 项 | 在哪里改 | 现状（占位） |
|---|---|---|
| 系统名 | `SYSTEM_NAME` | `FountainHub` |
| **社团名** | `CLUB_NAME` | `示例编程社` |
| **口号 / 社训** | `CLUB_SLOGAN` | **空字符串**（故意留空，等你填） |

**首页与 `/about` 的文案**（社团简介、日常活动、社训大字等）分别在
`templates/index.html` 与 `templates/about.html`，都已写成**占位提示**并标了"使用者请替换"。

### 1.2 定位（与代码无关，是设计取向的出发点）

| 项 | 内容 |
|---|---|
| 系统性质 | 校园社团的内部管理后台，**服务端渲染的网页**，浏览器访问 |
| 使用者 | 指导老师 + 社长层（正社长 / 副社长）+ 组长 + 成员（约百人量级，含已毕业仍可登录者） |
| 成员构成 | 以低年级为主；**零基础可参加**；也有算法竞赛方向的进阶成员 |

### 1.3 视觉意象（**通用版**）

本项目的视觉语言刻意保持**极简、抽象、可替换**，只依赖两种装饰：

| 意象 | 说明 |
|---|---|
| **四角星** | 唯一的"点"装饰（线稿，极淡） |
| **双拱弧线组** | 唯一的"线"装饰（对称弧线，从"水幕/拱门"抽象而来） |

> ⚠️ **两条约束**：① 两者都必须**极淡、不抢内容**，只用于 Hero 角落与空状态；
> ② **不引入任何真实 Logo / 社徽图片** —— 界面里 Logo 位置一律用**中性圆形占位块**，
> 由使用者换成自己社团的标记（见 §10 约束 5）。

## 2. 设计目标（按优先级）

1. **清晰高于美观**：社团管理后台，姓名/学号/日期/状态/数字要能一眼可读、可扫视、可对比。为好看牺牲可读性一律否决。
2. **零基础友好**：第一次来的人要能自己完成「注册 → 等审核 → 登录 → 签到」。禁止技术黑话、英文报错、空白页。
3. **数据可视化一眼看懂**：**签到日历**是不解释也能明白的招牌。
4. **统一**：全站收敛到**一套 token + 一套组件**。
5. **有品牌感**：气质要在 Hero、状态页、空状态、图标系统里可感知，但**不依赖任何具体品牌素材**。
6. **可持续**：能被翻译成 **Bootstrap 5.3.3 原子类 + 少量自定义 CSS**。

| 失败 | `#FEEDEB` | `#C0392B` | 校验失败、删除、拒绝、403 |

| 中性/未激活 | `#F1F5F9` | `#6B7280` | 未分组、已禁用、无数据 |
| 成就/荣誉 | `#F7EFD6` | `#8A6A12` | 获奖、星级、里程碑（**唯一允许用金的语义**） |

> `service/AttendanceCalendarService` 里的色值必须与本节一致）。
>
> 📌 **原「学习热力图（七级绿）」已随该功能下线而撤销**（2026-10-04）。
> 本文不再定义七级绿色阶 —— 若二期要重做，请重新走一遍设计评审，不要从 git 历史里直接抄色值。

### 3.4 用色纪律

- 一屏之内**饱和色不超过 3 处**（品牌蓝 + 至多 2 个状态色；金色另算且 ≤ 3 处/页）。
- 不要用颜色填满整行/整卡表达状态 → 用"浅底 + 深字 + 小圆点或图标"。
- **深藏青只用于"面"，不用于正文文字**。
- 正文对比度 ≥ 7:1，辅助文字 ≥ 4.5:1。
- 表格正文一律 `#14141E`；**只有真正可点击的才用品牌蓝**（避免"每条都像超链接"）。

## 4. 字体与排版

### 4.1 字体栈

| 用途 | 字体栈 |
|---|---|
| 中文（全部界面） | `"Microsoft YaHei", "PingFang SC", "HarmonyOS Sans SC", "Source Han Sans SC", system-ui, sans-serif` |
| 拉丁/数字 | `fh.css` **不引入任何字体 CDN**，拉丁/数字直接落到中文系统栈（`--fh-font`）。字重只用 400 / 500 / 600，**禁止 700 以上** |
| 数字强调（统计、学号、分数、排行） | `'Roboto Mono', ui-monospace, Consolas, monospace`（等宽数字，纵向对齐） |
| 代码 / Markdown | `Consolas, Monaco, 'Roboto Mono', monospace` |

> ⚠️ 中英混排时中英文之间留约 `0.25em`；**中文不使用负字距**（负字距只给拉丁大字）。

### 4.2 字级（Desktop）

| 角色 | 字号 | 字重 | 行高 | 字距 | 用途 |
|---|---|---|---|---|---|
| Display | 56px | 600 | 1.05 | −1.5px | 首页 Hero 主标题（仅 1 处） |
| H1 | 40px | 600 | 1.1 | −1.2px | 页面主标题 |
| H2 | 28px | 600 | 1.25 | −0.5px | 区块标题 |
| H3 | 22px | 600 | 1.4 | −0.2px | 卡片标题 |
| H4 | 18px | 500 | 1.4 | 0 | 小标题、分组名 |
| Body | 16px | 400 | 1.63 | 0 | 正文、说明段 |
| Body-sm | 14px | 400 | 1.5 | 0 | **表格内容、表单值、导航项（主力字号）** |
| Caption | 12px | 400/500 | 1.4 | +0.2px | 时间戳、表头、辅助说明、标签内文字 |
| Metric | 32px | 600 | 1.0 | −0.5px | 统计大数字（等宽） |

### 4.3 排版纪律

- **一页最多 1 个 H1**；层级靠"字号 + 字重 + 颜色"，不靠下划线装饰。
- 表格与列表正文一律 `14px`，**不得超过 16px**。
- 数字一律等宽 + `font-variant-numeric: tabular-nums`。
- 中文正文行高 1.6–1.8；长文本行长控制在 640–760px。
- 中文标题**不要**全大写、不要拉太开的 letter-spacing。

## 5. 间距 / 圆角 / 阴影

### 5.1 间距刻度

`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 56 / 80 px`

> ⚠️ **实测补充**：`fh.css` 里**只建到 `--fh-s10: 40px`**（4/8/12/16/20/24/32/40 有 token）；
> **56 / 80 没有 token**，实现时按需裸写值。本节刻度保留为"允许的间距语言"。

| 用途 | 值 |
|---|---|
| 卡片内元素间距 | 12px |
| 卡片内边距 | 28–32px（小卡 24px） |
| 表格单元格 | 横向 16px、行高 44–48px |
| 区块之间 | 56–80px |

**密度基调**：compact-to-comfortable —— 后台列表偏紧凑，首页与新闻页偏舒展。

### 5.2 布局

| 项 | 值 |
|---|---|
| **站点容器** | ⭐ **1200px** 居中，左右各留 24px |
| 居中表单卡（登录/注册/改密/忘记密码/错误页） | 单列 460–560px，垂直居中 |
| 栅格 | 12 列，列间距 24px（后台表单 3–4 列） |
| 页面结构 | 标题区 → 提示区 → 内容卡片（可多张）→ 底部说明 |

### 5.3 圆角（两级 + 药丸）

| 元素 | 圆角 |
|---|---|
| 按钮 / 标签 / 胶囊 / 导航项 / 头像 | **9999px（药丸）** |
| 输入框 / 下拉框 | 12px |
| 内层小卡（表格行卡、列表项、小组卡、新闻行） | 12–16px |
| 外层容器卡（页面主卡片、区块容器） | 20–24px |
| 大区块 / Hero 面板 | 32–40px |
| 图标容器 | 8px |
| Logo 占位块 | 圆形 |
| **签到日历格子** | 2–3px（**全站唯一允许小圆角**，因需密排；尺寸 14px 高 / 3px 间距） |

> 🚫 **全站不允许出现 0px 直角**（日历格子是唯一例外）。

### 5.4 阴影（同一屏不超过两种）

| 名称 | 值 | 用途 |
|---|---|---|
| 最轻 | `0 1px 2px rgba(2,5,32,.05)` | 标签、胶囊 |
| 小卡 | `0 1px 3px rgba(2,5,32,.07)` | 列表项、内层小卡 |
| **标准卡（默认）** | `0 1px 2px rgba(2,5,32,.05), 0 8px 24px -12px rgba(2,5,32,.10)` | 内容卡片 |
| 浮层 | `0 12px 40px -16px rgba(2,5,32,.18)` | 弹窗、下拉 |
| 品牌光晕（克制，≤3 处/页） | `0 8px 32px -12px rgba(20,90,255,.28)` | 主按钮 hover、重点数据卡 |

### 5.5 描边

- 默认 `1px #E2E8F0`；输入框 `#CBD5E1`
- 选中：`1px 品牌蓝` + `3px #E8EFFF` 外环
- 焦点：`0 0 0 3px rgba(0,153,255,.25)` + 边框 `#0099FF`
- 金色 `1px #C9A227`：**仅**Logo 占位框与成就卡

## 7. 导航信息架构（**结构已定型，不得改动**）

```
主导航（五段式，全站统一）：
   FountainHub · 〈社团名〉   首页  社团介绍  新闻  [管理]  我的      你好，XXX [退出登录]
                               ↑      ↑       ↑      ↑      ↑
```

## 9. 状态与反馈规范（全站唯一一套）

| 类型 | 结构 | 位置 |
|---|---|---|
| **A 成功提示（页面级）** | `#EDFBF0` 底 + 绿左条或圆点 + 文案 + 可关闭 | 页面/卡片顶部 |
| **B 失败提示（页面级）** | `#FEEDEB` 底 + 红图标 + 文案 + 可关闭 | 页面上方 |
| **C 字段级错误** | 输入框红边 + 下方 12px 红字（可加图标） | **紧贴该字段** |
| **D 空状态（必须分 4 种）** | ① **无数据**（灰 + 方框线稿，平静）② **无结果**（灰 + 放大镜 + 清空筛选）③ **【空栏占位】**（品牌蓝 + 线稿，期待感）④ **无权限**（锁） | 表格/列表区域内居中 |
| **E 加载中** | ① 骨架屏（列表/表格/卡片首次加载）② 局部 spinner + "处理中…"（提交、上传） | 内容区 / 按钮内 |
| **F 确认类** | 二次确认（删除 / 拒绝申请 / 代打卡 / 恢复默认背景） | 覆盖层 |

**硬性要求**：
- 所有提示**必须"颜色 + 文字或图标"双通道**，不允许只靠颜色。
- 动效只用 ≤200ms 淡入，**不要夸张动画**。
- ⭐ **"空栏占位"必须与"无数据"在视觉上明显不同**（前者是"期待"，后者是"空"）。

## 10. 实现约束（回填给代码）

| # | 约束 |
|---|---|
| 1 | **技术栈 = Thymeleaf 服务端渲染 + Bootstrap 5.3.3**；没有构建工具处理样式。**自研 CSS 是主体**，Bootstrap 只当"栅格 + 登录弹窗"用 |
| 2 | **样式落点**：**全站唯一 CSS = `src/main/resources/static/css/fh.css`**（一套 `--fh-*` 设计 token 全在里面）+ 外壳 `templates/fragments/layout.html`（导航/子导航/页脚/登录弹窗）+ 图标集 `templates/fragments/icons.html`（内联 SVG）。页面私有样式留在各页 `<style>` 里 |

| 4 | **自包含**：字体用系统栈（不依赖字体 CDN）；图标用内联 SVG（不依赖图标字体 CDN）。**唯一 CDN = Bootstrap 5.3.3**（用途仅栅格与登录弹窗）。其余前端逻辑**全部自写、零依赖**：`static/js/{md,carousel,crop,upload}.js` |
| 5 | **零图片素材**：项目 `static/` 下**一张图都没有**；所有视觉靠色块、字重、间距、线条、SVG 实现；**Logo 位用中性圆形占位块**。<br>运行时图片一律来自上传目录 `./uploads/`（已加进 `static-locations`） |
| 6 | **签到日历是纯 CSS 格子**（项目已弃用图表库，历史上出现过白屏） |
| 7 | 🔒 **隐私红线**：**公开页面（首页 / 新闻列表 / 新闻详情 / 招新页 / 获奖墙）绝对不允许出现任何手机号**；成员列表页也不出现；**只有成员详情页（后台）可以显示** |
| 8 | 🔒 **只读 vs 可编辑必须视觉可分**（同一页里大量存在两种区域：我的资料、成员详情） |
| 9 | **中文优先**：文案为简体中文；不要出现英文占位文案（代码/技术名词除外） |
| 10 | **设备范围**：本期**只做电脑浏览器视口**（1440 / 1920），不做移动端适配 |
