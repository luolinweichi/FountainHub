# 04 · 部署方案

> 这份文档讲**怎么把它部署到一台服务器上**。
> 想在本机跑起来，见 [00-快速开始](00-快速开始.md)。
>
> 📌 **说明**：与作者个人规划有关的章节属于内部资料，**未随仓库发布**；
> 本文只保留**技术上的部署步骤**，对任何使用者都适用。

---

## 1. 目标架构

```
        浏览器
          │  HTTPS / HTTP
          ▼
   ┌──────────────┐
   │    Nginx     │  80 / 443   静态资源 + 反向代理
   └──────┬───────┘
          │  proxy_pass
          ▼
   ┌──────────────┐
   │ Spring Boot  │  8080        java -jar fountainhub.jar（Thymeleaf 渲染页面）
   └──────┬───────┘
          │  JDBC
          ▼
   ┌──────────────┐
   │    MySQL     │  3306       库 fountainhub（20 张表）
   └──────────────┘
          +
   ./uploads/                   上传的图片（独立目录，需备份）
```

**一个关键点**：这个项目**没有前端构建产物**（没有 npm / dist）。
Nginx 只需把 `/uploads/` 直接映射出去（或让应用自己映射），其余请求全部转给 8080 —— **部署比前后端分离的项目简单得多**。

## 2. 服务器要求

| 项 | 建议 | 验证 |
|---|---|---|
| 操作系统 | **Ubuntu 24.04 LTS**（推荐）；22.04 也可，见下方 ① | `lsb_release -a` |
| JDK | **21** | `java -version` |
| Maven | 3.6.3+（apt 版即可） | `mvn -v` |
| MySQL | 8.0+（Ubuntu 24.04 默认装 8.0.x） | `mysql --version` |
| Nginx | 任意近期版本（只有阶段 B 用得上） | `nginx -v` |
| 内存 | 2 GB 起（单体应用，占用不高） | `free -h` |

> ✅ **实测状态**：作者已完成 **本机 Windows 开发 + 本机 Linux 虚拟机（Ubuntu 22.04.5 LTS Server）预演**，
> jar 已能在虚拟机里用 `./start.sh` 起来、数据库 20 张表就绪。
> ⚠️ 但**没有做过公网部署**（本项目不对外运营），所以下面关于 **Nginx / 域名 / HTTPS / systemd 开机自启**
> 的部分属于**标准做法**，**没有"我真的上线跑过"的背书** —— 遇到问题欢迎开 Issue。

## 3. 部署步骤

### ① 装依赖

```bash
sudo apt update

# JDK 21
#   Ubuntu 24.04：默认源里就有，直接装
sudo apt install -y openjdk-21-jdk
#   Ubuntu 22.04：若上面报 "Unable to locate package"，改用 Adoptium 官方源：
#     sudo apt install -y wget apt-transport-https gnupg
#     sudo mkdir -p /etc/apt/keyrings
#     wget -qO - https://packages.adoptium.net/artifactory/api/gpg/key/public \
#       | sudo tee /etc/apt/keyrings/adoptium.asc > /dev/null
#     echo "deb [signed-by=/etc/apt/keyrings/adoptium.asc] https://packages.adoptium.net/artifactory/deb $(awk -F= '/^VERSION_CODENAME/{print$2}' /etc/os-release) main" \
#       | sudo tee /etc/apt/sources.list.d/adoptium.list
#     sudo apt update && sudo apt install -y temurin-21-jdk

# Maven（apt 版是 3.6.x —— 刚好满足 Spring Boot 3.3 的最低要求 3.6.3）
sudo apt install -y maven

# MySQL 与 Nginx
sudo apt install -y mysql-server nginx

# 验证
java -version     # 应显示 21
mvn -v            # 应显示 3.6.3 或更高
```

### ② 建库 + ⭐ **建一个应用专用账号**（Ubuntu 特有的一步）

> 🔴 **Ubuntu 的 MySQL `root` 默认用 `auth_socket` 插件** ——
> 也就是**只能用 `sudo mysql` 免密进去**，**不能用"用户名 + 密码"从 TCP 连**。
> 而本项目是通过 JDBC 用**用户名 + 密码**连的 → **直接用 root 会认证失败**。
> 所以这里建一个专用账号给应用用。（Windows 上装的 MySQL 默认是密码认证，所以没这一步。）

```bash
sudo mysql <<'SQL'
CREATE DATABASE IF NOT EXISTS fountainhub
  DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- ⚠️ 把 fh 和下面的密码换成你自己的
CREATE USER IF NOT EXISTS 'fh'@'localhost' IDENTIFIED BY '换成你的密码';
GRANT ALL PRIVILEGES ON fountainhub.* TO 'fh'@'localhost';
FLUSH PRIVILEGES;
SQL
```

导入表结构（**顺序不能乱**）：

```bash
# 用 root 免密导（也可以改成 -u fh -p 用上面那个账号导）
sudo mysql fountainhub < sql/01-schema.sql
sudo mysql fountainhub < sql/02-seed.sql
sudo mysql fountainhub < sql/03-add-password-reset-requests.sql
sudo mysql fountainhub < sql/04-add-site-settings.sql
sudo mysql fountainhub < sql/05-add-checkins.sql
sudo mysql fountainhub < sql/06-add-must-change-password.sql   # 🆕 2026-10-07

# 核对：应该是 20 张表
sudo mysql fountainhub -e "SHOW TABLES;" | wc -l
```

> `sql/03`~`sql/06` 都是**幂等**增量脚本（能重复跑、已存在时自动跳过），**全新安装也建议照单全跑** ——
> 省得记"哪几个要跑、哪几个不用"，而且将来 `01` 若没同步某张表，全跑就不会漏。
>
> 🔴 **`sql/06` 必须"先跑脚本、再启动应用"**：应用里是 `ddl-auto: validate`（**只校验、不改表**），
> 数据库缺 `must_change_password` 这一列就启动新 jar → **应用会直接启动失败**（不会损坏任何数据，补跑脚本再重启即可）。

### ③ 写应用配置（**不进 Git，必须手动创建**）

新建 `src/main/resources/application-local.yml`：

```yaml
spring:
  datasource:
    username: fh              # ⚠️ Ubuntu 上要填 ② 里建的账号，不是 root
    password: 换成你的密码
```

> ⚠️ 这个文件**已被 `.gitignore` 忽略**，所以 clone / 解压下来是**没有它**的。
> 不创建它，应用启动就会报 `Access denied` / 连不上库。

### ④ 设置初始账号密码（环境变量，别写进文件）

```bash
export FH_INIT_PASSWORD='你自己想的密码'
```

> 首次启动且 `users` 表为空时，程序会用它创建 3 个测试账号
> （`teacher` / `president` / `student`）。**不设这个变量 → 不建账号** ——
> 故意不设默认值，否则等于"代码里藏了个众所周知的密码"。

### ⑤ 先跑一遍（开发模式，**推荐先做这步**）

```bash
cd ~/fountainhub          # 项目目录
mvn spring-boot:run
```

看到 `Started FountainHubApplication` 就成功了。然后：

```bash
# 虚拟机上先自测（应返回 pong）
curl http://localhost:8080/ping
```

**从 Windows 浏览器访问**：`http://<虚拟机IP>:8080`

```bash
# 查虚拟机 IP
hostname -I

# ⚠️ 如果 Windows 上打不开，放行防火墙（Ubuntu 默认 ufw 可能是关的；
#    但若开着，必须放行 8080）
sudo ufw allow 8080/tcp
sudo ufw status
```

> 💡 这一步（`mvn spring-boot:run`）**只是先把功能跑通**。
> 跑通之后再往下做 ⑥⑦（jar + systemd + Nginx），那才是长期稳定的方式。

### ⑥ 打包 + 用 systemd 托管

```ini
# /etc/systemd/system/fountainhub.service
[Unit]
Description=FountainHub
After=network.target mysql.service

[Service]
User=fountainhub
WorkingDirectory=/opt/fountainhub
Environment="FH_INIT_PASSWORD=你自己想的密码"
ExecStart=/usr/bin/java -jar /opt/fountainhub/fountainhub.jar
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now fountainhub
sudo systemctl status fountainhub
```

### ⑦ Nginx 反向代理

```nginx
server {
    listen 80;
    server_name your-domain.example;

    client_max_body_size 10m;          # 与 spring.servlet.multipart.max-request-size 保持一致

    location /uploads/ {
        alias /opt/fountainhub/uploads/;
        expires 7d;
    }

    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

```bash
sudo nginx -t && sudo systemctl reload nginx
```

## 4. 安全要点

| 项 | 做法 |
|---|---|
| 防火墙 / 安全组 | **只开 22（SSH）、80、443**；**3306 绝不对公网开放**<br>⚠️ Ubuntu 若开了 `ufw`：开发期要 `sudo ufw allow 8080/tcp`，正式上线后应改成只放行 80/443 |
| 数据库密码 | 放 `application-local.yml`（已忽略）或环境变量，**绝不提交** |
| 初始账号密码 | 走环境变量 `FH_INIT_PASSWORD`；**上线后第一件事是登录改掉它** |
| 上传目录 | 独立目录（`fountainhub.upload.dir`），不要把 jar 和它混在一起 |
| 备份 | 至少备份两样：**MySQL 的 `fountainhub` 库** + **`uploads/` 目录** |
| 反向代理 | 应用只监听 `127.0.0.1:8080`（不要 `0.0.0.0`），由 Nginx 对外 |

## 5. 升级流程

```bash
# 1) 备份（先备份，再升级）
mysqldump -u root -p fountainhub > backup-$(date +%F).sql
tar czf uploads-$(date +%F).tar.gz /opt/fountainhub/uploads

# 2) 换 jar
mvn -DskipTests package
sudo systemctl stop fountainhub
sudo cp target/*.jar /opt/fountainhub/fountainhub.jar
sudo systemctl start fountainhub
```

> ⚠️ **表结构变更要小心**：本项目用的是 `spring.jpa.hibernate.ddl-auto: validate` ——
> 应用**不会**自动改表。所以升级时若带了新的 SQL 脚本，**要先跑脚本再启动应用**，
> 否则会因为"实体与表对不上"直接启动失败。
