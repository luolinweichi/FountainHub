## 1. 任务理解

**A. 后台总览**（FR-11.1）—— 新建 `/admin`：总人数 / 本周做题 / 本周签到 / 考勤活动 / 各组人数 / 做题排行榜

**B. 两个导出接口**（FR-6.12）—— ⭐ **点哪个导哪个**：
```
/admin/attendance/export/weekly   ← 仅例行活动（"必到那天谁没来"）
/admin/attendance/export/all      ← 全部日期（含平时的日常开放）
```

**表格格式（项目负责人定的）**：
```
        │ 9月23日 │ 9月30日 │ 10月7日 │ 10月14日 │
────────┼─────────┼─────────┼─────────┼──────────┼
luo     │         │         │         │          │
普通社员 │         │   ✓     │         │          │
```
行 = 学生；第一列 = 姓名；后面 = 日期；**到了打 ✓，没到就空着**（不写「缺席」两个字）。

## 2. ⚠️ 关于文件格式：**没能用上 POI**（如实说明）

项目负责人选的是 **Apache POI 真 .xlsx** ✅，但**我这边加不上这个依赖**：

```
本地 Maven 仓库：C:\Users\<你的用户名>\.m2\repository\org\apache\poi
  ❌ 没有 poi 目录；❌ poi-ooxml；❌ xmlbeans（poi-ooxml 的依赖）
而开发沙箱【没有外网】、也【不让写 .m2】→ Maven 下载不了 → 依赖加不上
```

**当前实现：CSV（带 UTF-8 BOM）**

| ✅ 好处 | ❌ 局限 |
|---|---|
| 双击就能用 Excel / WPS 正常打开、能正常打勾、**不乱码**（有 BOM） | 文件是 `.csv`，**不是 `.xlsx`** |
| 接口地址、权限、内容、**文件名完全一样** | 列宽、表头样式控制不了 |

### 🔧 等 POI 到位后怎么换成真 .xlsx（**只改一个类**）

> 这些都写在了 `AttendanceExportController` 顶部的注释里 ✅

### ⚠️ 两个踩到的坑（都真发生了）

| # | 坑 | 后果 | 修法 |
|---|---|---|---|
| 1 | 往导航插「总览」链接时，**插进了另一个跨两行的 `<a>` 标签中间** | **整个 `layout.html` 解析失败 → 全站所有页面（连登录页）都 500** ❌ | 重写那段 nav + 加「标签结构检查」 |
