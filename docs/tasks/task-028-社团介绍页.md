## 4. 实现步骤（草案）

1. **先确认现状**：读 `fragments/layout.html`（`head` / `nav` / `footer` 三个 fragment）与 `fh.css`，确认可复用的 class 清单
2. 新建 `AboutController`：`@GetMapping("/about")` → `return "about"`（**不需要 model 数据**，本页纯静态）
3. 新建 `about.html`，按 **①→⑫** 顺序搭骨架：
   - `head` 用 `th:replace` 引 `head('社团介绍')`
   - `nav` / `footer` 用 `th:replace` 引公共 fragment
   - 内容用**占位文字**（"标题占位""正文占位（约 60 字）"），并在每个区块上加 HTML 注释标明**区块序号**
4. 图片位用**占位块**：浅灰底 + 山形线稿 + "暂无图片" + 建议尺寸（可复用 `fh.css` 里已有的占位思路）
5. 手风琴（⑨）：**优先用纯 CSS 实现**（`<details>/<summary>` 或 checkbox hack），保证无 JS 也能展开；不引第三方库
6. 自检：全页搜 `138` / 手机号格式 / 人名 → **必须为 0**；金色出现次数 → **≤ 2**
7. 手动验证（见 §6）

> 💡 **文案后填时**：建议把文案集中在模板顶部用 Thymeleaf `th:with` 定义变量，或直接写在对应位置并加 `<!-- TODO 文案 -->` 注释，方便你后面一次性替换。
