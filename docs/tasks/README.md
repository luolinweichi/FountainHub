# tasks/ · 任务书文件夹

**约定**：**一个任务一个文件**，文件名形如 `task-001-user实体与仓库.md`（编号与 [../plan.md](../plan.md) 的 T-XXX 对应）。

每份任务书固定写这 7 块（对应 [../../AGENTS.md](../../AGENTS.md) §5 的要求）：

1. **目标**（这个任务要达成什么）
2. **非目标**（明确不做什么）
3. **计划修改的文件**
4. **实现步骤**
5. **风险与不确定点**
6. **验证命令**（项目负责人照着敲就能验证）
7. **完成记录**（真实结果 + 日期）

> 规则：**未经项目负责人确认，不开始实现**（见 `AGENTS.md` §5）。
