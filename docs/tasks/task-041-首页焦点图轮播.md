## 1. 目标（这个任务要达成什么）

把首页从「Hero + 最新新闻 + 功能卡 + 进度」升级为**信息更完整的对外门面**，顺序如下：

```
① 导航栏（不变）
② Hero 面板：社团名 + 主口号（配 1px 金色细线）
   + 一句简介 + 游客「注册加入」主按钮（已登录则显示问候 + 资料/改密入口）
   + 极简「双拱水幕 + 四角星」线稿装饰
③ ⭐ 焦点图轮播（新增）
④ 左右两栏：**左「社团简介」（窄 1/3）/ 右「最新新闻」（宽 2/3）**（新增）
⑤ 功能入口卡（按角色，最多 4 张，未开发页标"即将上线"不放死链）
⑥ 系统建设进度（8 条两列）
```

### 焦点图轮播规格（设计已定）

| 项 | 值 |
|---|---|
| 尺寸 | 宽 1200px（与容器同宽），高 360–420px，圆角 32–40px，图片覆盖式裁切 |
| 内容 | **3–5 张焦点/重要新闻**的封面图；图上叠加「标题 + 分类标签 + 日期」；整张可点进详情 |
| 取数规则 | 🔒 **只取"已发布"且"对外公开（非仅登录可见）"的新闻**（与 T-026 / T-027 同一条规则） |
| 排序 | 置顶优先，其次按发布时间倒序 |
| 控件 | 左右箭头（半透明圆形）+ 底部圆点指示器（当前页实心）+ **5 秒自动播放（hover 暂停）** |
| 无图时 | 显示图片占位（浅灰底 + 山形线稿 + "暂无封面图" + 建议尺寸 1200×400） |
| 空状态 | 一条都没有时显示**默认横幅**（社团名 + 主口号 + 双拱水幕线稿），不留空白 |
| 图片比例 | 建议 **1200 × 400**（约 16:5.3），上传后自动覆盖裁切 |

- ❌ 不做"轮播后台管理页"（复用现有新闻的封面图与置顶/发布状态，**不新增表**）
- ❌ 不动 `/about` 招新页（那是 **T-028**）

**② 封面裁剪（新增，纯前端 Canvas，零依赖）**

| 文件 | 内容 |
|---|---|
| `static/js/crop.js` | **新建**（114 行）：拖动调位置 + 滑杆缩放 + 固定 3:1 框 → Canvas 输出 **1200×400** |
| `static/css/fh.css` | 改：加裁剪弹框样式 |
| `admin/news-form.html` | 改：封面 handler 改成「**先裁剪再上传**」（正文插图不受影响） |

- **为什么先裁再传**：轮播是 1200×400，用户随手传的 4:3 / 16:9 / 竖图若只靠 `object-fit:cover` 硬裁，很容易把标题或人脸切掉；
- **为什么自己写不用 Cropper.js**：项目原则**不引新依赖**、需求简单（固定 3:1、不需旋转翻转）、第三方库在沙箱里还可能加载不到。
