## 4. 实现步骤

1. 新建 `ProfileController`（`@RequestMapping("/me")`）
2. `GET /me/password` → 表单页
3. `POST /me/password` → 四道校验 → 存新哈希 → 强制重新登录
4. `login.html` 加「密码已修改，请用新密码登录」
5. 编译 → 端到端验证（含「改回去」保持环境干净）
6. 更新文档

## 5. 风险与不确定点

| # | 风险 | 处置 |
|---|---|---|
| 1 | ⚠️ **必须用 `passwordEncoder.matches()` 校验旧密码**，不能自己写比较 | 已按此实现；注释写明「绝不能写成 equals」 |
| 2 | 校验顺序 | 旧密码 → 长度 → 两次一致 → 新旧不同（由便宜到昂贵） |
| 3 | 改完是否强制重新登录 | **是**（更安全，也顺便验证新密码确实生效）→ 实测通过 |
| 4 | 从哪取「当前用户」 | **从会话取**（`authentication.getName()`），**不从 URL 取** —— 否则改一下地址栏就能改别人密码 |
| 5 | 验证需要第二个账号 | 用测试账号 `test001`，**不动 admin 的密码** |
| 6 | 目前 `/me` 下没有任何导航入口 | 页面里放了「回到首页」链接；完整导航是 T-027 的事 |
