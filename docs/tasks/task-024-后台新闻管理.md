## 1. 任务理解

给社长层一个管新闻的地方：**列表 / 新建 / 编辑 / 删除 / 草稿↔发布 / 置顶 / 分类**。

### ⭐ 正文用 Markdown（项目负责人要求）

> 「用 b 但是我想加一个 markdown 文本编辑器。看吧，如果没办法实现，你就使用 b，
> 然后如果可以的话，就用 c 加上一个 markdown。」

**为什么没用 C（富文本编辑器）**

| 方案 | 结论 |
|---|---|
| C 富文本编辑器 | ❌ **只能靠 CDN**（编辑器 + Markdown 库）→ **和 ECharts 同一个坑**：CDN 挂了整个功能空白，而 AI 沙箱没外网**没法验证** |
| **B + Markdown（采用）** | ✅ **自己写一个约 110 行的渲染器**（`static/js/md.js`），**零依赖、零 CDN** |

> 💡 留给「优化阶段」：等 M9 做完开始优化时，如果你还想要真正的富文本编辑器，
> **那时候你自己的机器能测**，风险就小多了 ✅

## 2. 编辑器长这样

```
┌─ 正文（支持 Markdown）─────────────────────────┐
│ [B] [H1] [H2] [列表] [有序] [链接] [图片] [代码] [引用] │  ← 点了往光标处插语法
│ ┌──────────────┬──────────────────────┐      │
│ │ ## 例行活动   │ 例行活动（大标题）     │      │
│ │ **快速排序**  │ 快速排序（加粗）       │      │  ← 左写右看
│ │ - 递归        │ • 递归                │      │
│ └──────────────┴──────────────────────┘      │
└──────────────────────────────────────────────┘
```

## 3. ⚠️ 安全：XSS 必须防住（本任务的红线）

**渲染器 `md.js` 的第一件事就是转义 HTML，然后才解析 Markdown** ✅

```javascript
var s = mdEscape(src);   // ① 先转义 < > & " '
s = s.replace(...);      // ② 再解析 Markdown
```

**顺序反了会怎样**：正文里写 `<script>alert(1)</script>` 就会被**真的执行** ❌
转义之后它变成 `&lt;script&gt;...`，**只会被当文字显示** ✅

另外还挡掉了 `javascript:` / `data:` / `vbscript:` 开头的链接 ✅

> 【最坏情况】就算这个脚本没加载，页面显示的也是 **Markdown 原文** ——
> 内容照样看得见，**不会白屏** ✅ 这比 ECharts 那次安全得多。

## 4. 🔒 防批量赋值

表单**只接收 4 个字段**：`title` / `category` / `content` / `isInternal`。

否则有人改一下表单就能把自己设成「置顶 + 已发布」，或者冒充别人发布 ✅

### ⚠️ 那 1 条「失败」的真相

我的断言是「删除后页面上**不应再出现**『注入测试』这个字符串」。
但删除成功后，页面顶部会显示红/绿提示：**「已删除：注入测试」** ——
所以字符串**当然还在** ✅ 是**我的断言没排除提示信息** ✅
（已查库确认：`SELECT COUNT(*) FROM news WHERE title='注入测试'` = **0** ✅ 删干净了）

> 👉 **教训（第三次了）**：用「页面上有没有某个字符串」做断言时，
> **一定要先排除提示语/导航/页脚这类外壳**，否则很容易误判。

### 另一个假警报

模板扫描器把 `th:action="${isNew} ? @{...} : @{...}"` 标成了「链接表达式写错」——
其实那是**合法的 Thymeleaf 条件链接表达式**（`@{...}` 嵌在 `${...}` 里）✅
运行验证通过（新建页 200 ✅），说明是**扫描器误报**，不是真问题 ✅
