## 📐 技术栈一览

| 项 | 值 |
|---|---|
| 语言 / 框架 | Java 21 · Spring Boot 3.3.5 |
| 视图 | **Thymeleaf 服务端渲染**（不引入 React / Vue） |
| 样式 | Bootstrap 5（仅栅格与弹窗）+ 自建设计 token（`static/css/fh.css`） |
| 持久化 | Spring Data JPA + MySQL（`ddl-auto: validate`，表由 SQL 脚本手工建） |
| 规模 | 81 个 Java 文件 / 约 5,400 行 · 31 个页面模板 · 29 个 Controller · 20 张表 |
| 前端依赖 | **零构建**（没有 npm / webpack / vite），只用 CDN 引 Bootstrap |

## 📁 目录速查

```
docs/            你正在看的这些文档
sql/             建库脚本（01 建表 → 02 示例数据 → 04 增量补表）
src/main/java/   后端（controller / service / repository / entity / security / config / util）
src/main/resources/templates/   Thymeleaf 页面
src/main/resources/static/      css / js（无构建，直接引）
```
