### 1.4 启动

| 方式 | 操作 |
|---|---|
| **IDEA（推荐）** | 右键 `FountainHubApplication` → Run |
| **命令行** | `cd /d D:\Project\FountainHub` 然后 `mvn -B -ntp spring-boot:run` |

**成功标志（看控制台）**：

```
HikariPool-1 - Start completed.                    ← 数据库连上了
Initialized JPA EntityManagerFactory              ← 实体映射校验通过（ddl-auto: validate）
Tomcat started on port 8080 (http)
Started FountainHubApplication in x.xxx seconds
```

**❌ 如果启动失败，按这几条对号入座**：

| 报错关键字 | 原因 | 怎么办 |
|---|---|---|
| `Access denied for user` | `application-local.yml` 里的密码不对 | 改密码 |
| `Communications link failure` | MySQL 服务没启动 | 启动 `MySQL267` 服务 |
| `Schema-validation: missing column` | 实体字段与数据库表**对不上** | 别再猜了，把报错原文贴出来 |
| `Web server failed to start. Port 8080 was already in use` | **8080 被占了**（最常见：上一次的实例没关） | IDEA 里点红色 ⏹ 停掉旧实例；或换端口 `--server.port=8081` |
| `Unknown database 'fountainhub'` | 库没建 | 执行 `sql/01-schema.sql` |

## 6. 手动测试之外的辅助手段

### 6.1 用命令行验证接口（不用打开浏览器）

```powershell
# 简单探活
Invoke-WebRequest -UseBasicParsing http://localhost:8080/ping | Select-Object -ExpandProperty Content
```

> ⚠️ **PowerShell 的 `Invoke-WebRequest` 看不到 302 的详情**（会报「对象的当前状态使该操作无效」）。
> 要测重定向，改用 **Node**（本次盘点期间一直这么做）：

```js
import http from "node:http";
http.get({ host: "127.0.0.1", port: 8080, path: "/admin/students" }, (res) => {
  console.log(res.statusCode, res.headers.location);   // 302 + /login 才是对的
});
```

### 6.2 数据库侧验证

```cmd
"C:\Program Files\MySQL\MySQL Server 26.7\bin\mysql.exe" --default-character-set=utf8mb4 -u root -p fountainhub -e "SELECT id, username, real_name, role, status, LENGTH(password_hash) AS hash_len FROM users;"
```

**预期**：每行的 `hash_len` 都是 **60**（BCrypt 的特征），且**看不到任何明文密码**。

> ⚠️ **Windows 上用 mysql 客户端跑含中文的脚本，一定要加 `--default-character-set=utf8mb4`**，
> 否则会报 `ERROR 1366 Incorrect string value`（本次盘点期间踩过）。
