# 00 · 快速开始（跑起来 + 改成你自己社团的）

> **这份文档只解决两件事**：
> ① **5 分钟把它跑起来**；② **改几处，它就变成你自己社团的管理系统**。
> 全部步骤都是照着敲就能跑的，不需要额外查别的文档。

---

## 一、环境要求

| 需要 | 版本 | 验证命令 |
|---|---|---|
| JDK | **21** | `java -version` |
| Maven | 3.9+ | `mvn -v` |
| MySQL | 8.0+ | `mysql --version` |

> 本项目**只用 CDN 引 Bootstrap**，没有 npm / webpack / vite —— **不需要任何前端构建环境**。

## 二、建库 + 建表（⚠️ 顺序不能乱）

```sql
-- 1) 先建库（字符集必须是 utf8mb4，否则中文会乱码）
CREATE DATABASE fountainhub DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

```bash
# 2) 再按顺序跑脚本（文件名前的数字就是顺序，六个都要跑）
mysql -u root -p fountainhub < sql/01-schema.sql                     # 建 19 张表
mysql -u root -p fountainhub < sql/02-seed.sql                       # 塞示例数据（新闻 / 分组）
mysql -u root -p fountainhub < sql/03-add-password-reset-requests.sql
mysql -u root -p fountainhub < sql/04-add-site-settings.sql          # 第 20 张表：site_settings
mysql -u root -p fountainhub < sql/05-add-checkins.sql
mysql -u root -p fountainhub < sql/06-add-must-change-password.sql   # users 加"首次登录强制改密"列
```

| 脚本 | 作用 | 全新安装要跑吗 |
|---|---|---|
| `01-schema.sql` | 建全部业务表（19 张） | ✅ 要 |
| `02-seed.sql` | 示例分组 + 3 条示例新闻 | ✅ 要（**不跑就没有示例数据，页面会是空的**） |
| `03-add-password-reset-requests.sql` | 给**老库**补"忘记密码"那张表 | ✅ 要跑（幂等，`01` 已含时自动跳过） |
| `04-add-site-settings.sql` | 第 20 张表：站点设置（首页背景图） | ✅ 要 |
| `05-add-checkins.sql` | 给**老库**补回 `checkins` 表 | ✅ 要跑（幂等，`01` 已含时自动跳过） |
| `06-add-must-change-password.sql` | **users 加 `must_change_password` 列**（首次登录强制改密） | ✅ **要**（🆕 2026-10-07） |

> ⚠️ **`06` 必须"先跑脚本、再启动应用"**：应用里是 `ddl-auto: validate`（只校验不改表），
> 数据库缺这一列就启动新版本 → **应用会直接启动失败**。

> 跑完一共 **20 张表**。

## 三、配数据库密码（**不进 Git**）

项目**故意不在主配置里写密码**。密码放在一个被 `.gitignore` 忽略的私有文件里：

**新建** `src/main/resources/application-local.yml`：

```yaml
spring:
  datasource:
    password: 你的MySQL密码
```

> 📌 **为什么这么设计**：`application.yml` 里只有 `spring.profiles.active: local,dev`，
> 真正的密码在 `application-local.yml` —— 这个文件**永远不会被提交**。
> 这样"能跑的项目"和"能公开的仓库"就不冲突了。

## 四、设置初始账号密码（环境变量）

```powershell
# PowerShell
$env:FH_INIT_PASSWORD = '你自己想的密码'
mvn spring-boot:run
```

```bash
# Linux / macOS
export FH_INIT_PASSWORD='你自己想的密码'
mvn spring-boot:run
```

IDEA 用户：`Run/Debug Configurations` → `Environment variables` 里加 `FH_INIT_PASSWORD=...`。

> 📌 **为什么是环境变量**：源码里**没有任何明文密码**。
> 首次启动时如果数据库是空的，程序会用这个变量建 3 个账号；
> **没设变量 → 不建账号**（并打一条 WARN 告诉你怎么设）—— **故意不设默认值**，
> 否则等于"代码里藏了个众所周知的密码"。

```
http://localhost:8080
```

首次启动且空库时，会自动建 **3 个测试账号**（**同一个初始密码**，就是上面那个环境变量）：

| 用户名 | 角色 | 用来干什么 |
|---|---|---|
| `teacher` | 指导老师 | 全部权限 |
| `president` | 正社长 | 管理学员 / 考勤 / 新闻 / 获奖 / 分组 |

> 💡 学员账号支持 **用户名 / 学号 / 手机号** 三种方式登录（选一种填就行）。

## 六、⭐ 改这几处 = 变成你自己社团的

> 💡 **怎么找全部待填点**：在项目里全局搜 **`【请填写`** —— 命中多少处，就有多少处要改成你自己的。

| # | 改什么 | 改哪个文件 | 现在是什么 |
|---|---|---|---|
| **1** | **社团名**（导航栏、页脚、登录页、首页、/about 全站生效） | `src/main/java/com/fountainhub/config/GlobalModelAdvice.java` **第 39 行** `CLUB_NAME` | `示例编程社` |
| **2** | **口号 / 社训**（首页 Hero、/about 的大字、页脚） | 同文件 **第 50 行** `CLUB_SLOGAN` | **空字符串**（故意留空） |
| **3** | 系统名（一般不用改） | 同文件 第 28 行 `SYSTEM_NAME` | `FountainHub` |
| **4** | ⭐ **首页文案**（Hero 那句介绍 + 5 个标签 + 社团简介 + 社训） | `src/main/resources/templates/index.html` | 全是 **`【请填写：…】` 占位** |
| **5** | ⭐⭐ **社团介绍页 `/about` 整页** | `src/main/resources/templates/about.html` | **25 处 `【请填写：…】` 占位**；12 个区块的**结构与样式已定稿，不用动**，只填文字（想删区块就整块删） |
| **6** | **考勤活动类型名称**（下拉框那两项 + 导出文件名） | `src/main/java/com/fountainhub/entity/AttendanceType.java` 的两行 `label` | `例行活动（必到）` / `日常开放（自愿）` —— 按你们实际叫法改（如「周三例会」「周末集训」） |
| **7** | **示例数据**：新闻 / 分组 / 首页背景图 | 后台页面（`/admin/news` · `/admin/groups` · `/admin/settings`） | 3 条示例新闻 + 1 个「示例组」 |

> ⚠️ 改 **1 / 2 / 3 / 6** 之后**必须重启**（它们是编译进程序的 Java 常量）；
> 改 **4 / 5** 只要刷新页面（模板缓存是关的）；**7** 在后台点鼠标就行。

**不用改的**（这些是通用词，任何社团都适用）：`成员` · `学号` · `社团` · `考勤` · `分组` · `获奖` · `新闻`。

## 八、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 启动报 `Schema-validation: missing table ...` | 表没建全 | 按 **01 → 02 → 04** 的顺序重跑（`ddl-auto` 是 `validate`，程序**不会**替你建表） |
| 启动成功但**一个账号都登不上** | 没设 `FH_INIT_PASSWORD` | 设好环境变量再启动（日志里有 WARN 提示） |
| 改了社团名但页面没变 | 改的是 **Java 常量** | **重启**应用 |
| 改了模板但页面没变 | —— | 刷新即可（`spring.thymeleaf.cache=false`） |
| 上传的图片打不开（404） | 上传目录没被静态映射 | 上传目录由 `fountainhub.upload.dir` 配置，默认 `./uploads/`；用后台上传会自动创建 |
| 中文乱码 | 建库时字符集不对 | 库必须是 `utf8mb4` |
| 首页焦点图显示「暂无封面图」 | 新闻没配封面图 | **这是设计好的空状态**，不是 bug |
| **（Linux）** 启动报 `Access denied for user 'root'@'localhost'` | ⚠️ **Ubuntu 的 MySQL root 默认用 `auth_socket`**，只能用 `sudo mysql` 进去，**不能拿密码从 TCP 连** | 建一个应用专用账号，并把 `username` 也写进 `application-local.yml` —— 见 [04-部署方案](04-部署方案.md) 第 3 节 ② |
| **（Ubuntu 22.04）** `Unable to locate package openjdk-21-jdk` | 22.04 的默认源里没有 JDK 21 | 用 Adoptium 官方源装 `temurin-21-jdk` —— 见 [04-部署方案](04-部署方案.md) 第 3 节 ① |
| `mvn: command not found` | 本项目**不带 Maven Wrapper** | `sudo apt install -y maven`（或自己装 3.9.x） |
