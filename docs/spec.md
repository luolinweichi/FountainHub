## 0. 这份文档怎么用

1. **写任何一行功能代码之前**，先在这里确认：这件事「在范围内」且「有明确的验收标准」；
2. 这里没写的功能 = **不做**；想加 → 先改这份文档，再写代码；
3. 每完成一个任务，回来把对应验收项打勾（见第 4 节）；
4. **权威范围**：本文件的权威部分是 **第 3 节「不做什么」** 和 **第 4 节「验收标准」**；
   第 2 节「做什么」是 [01](01-需求规格说明书.md) 与 [03](03-一期P1实现清单.md) 的**浓缩索引**（明细看那两份，避免三处各写一份）。
5. 若与其它文档冲突：**以本文件为准**，并在第 6 节记录原因。
   📌 **实测优先**：若实测项目（代码 / 数据库 / 路由）与本文档不一致，**先以实测为准**，并立即修订本文档、在第 6 节写明原因。

## 1. 一句话目标

让**一个约百人规模的校园社团**能真正每天用起来的最小闭环：

> 登录 → 看自己的档案 → **到场签到、看到签到日历** → 看通知公告；
> 社长能管人、管考勤、管分组、导表。

## 2. 做什么（P1 范围）

### 2.1 必做（缺了系统不成立）

| 编号 | 模块 | 具体做什么 | 需求出处 |
|---|---|---|---|
| **T1** | 账号与登录 | 学号 / 手机号 / 用户名**任一 + 密码**登录；**成员自助注册 + 管理员审核**；可自行修改密码；待审核/禁用不能登录；⭐ **忘记密码 = 申请 + 社长审核**（见 T1.1） | FR-1.x |
| **T1.1** | ⭐ **忘记密码** | 登录页有「**忘记密码**」入口（**注意：不是"重置"**）→ 申请页填 学号/用户名/手机号（任一）+ 想设置的新密码 → 提交后进入**待社长审核** → 社长**审核通过后新密码才生效** → 拒绝则旧密码继续有效。⚠️ 全流程文案**不得出现"重置"二字** | FR-1.4 |
| **T2** | 成员档案 | 列表（按姓名/学号搜索、按组/状态筛选）、编辑、详情；**注册时一并填写档案**；成员**只能改自己的联系方式**；管理员可**手工补录**（一次建号 + 建档） | FR-2.x |
| **T3** | 分组管理 | 建组 / 改组名说明排序 / **指定组长** / **添加组员** / **删除组**（删组后组员自动变「未分组」）；**组长只能查看本组的姓名与人数**（不能修改、不能进后台） | FR-3.x |
| **T4** | 考勤签到 + 签到日历 | 「**你到场了没有**」—— 例行活动（全员必到）+ 日常开放（自愿），**去了就自主签到、没去就空着**；社长可**代打卡并记录是谁代打**；出勤率；导出考勤表（⚠️ **当前为 CSV（UTF-8 BOM）**，Excel / WPS 可直接打开）<br>🔄 **配色**：签到日历**两色** —— 未签到 `#DDE3E7` / 已签到 `#145AFF`（品牌蓝），色值由 `docs/08` 冻结 | FR-6.x |
| **T5** | 新闻公告 | 发布图文新闻（分类 / 封面图 / 多图 / 草稿 / 置顶）；公开列表与详情 | FR-9.x |
| **T6** | 公开首页 | 社团介绍 + **焦点图轮播** + 最新新闻 + 社团简介 + 登录入口；不登录也能访问<br>**首页结构** = Hero（社团名 + 主口号 + 简介 + 注册按钮）→ **焦点图轮播** → **左「社团简介」（窄，1/3）/ 右「最新新闻」（宽，2/3）两栏** → 功能卡片 → **「获奖公示」区块（无公开获奖时不渲染）** → 建设进度<br>**焦点图轮播**：3–5 张**已发布且对外公开**（非仅登录可见）的新闻封面，5 秒自动播放（hover 暂停）、左右箭头 + 圆点、整张可点进详情、**无封面时显示默认横幅** | FR-12.x |
| **T6.1** | ⭐ **站点设置 · 首页背景图** | 管理员（指导老师 / 正社长 / 副社长）在 `/admin/settings` **上传更换首页背景图**：**一张固定**、**只作用于首页**、需**半透明遮罩**保证文字可读、可**恢复默认背景**；有「显示效果预览」。存放方案：**`site_settings` 键值表**（键 `home_background`）；背景图铺满**整个首页**（导航以下 → 内容结束）+ **白色 40% 遮罩**，**未配置时与默认完全一致** | FR-12.6 |

## 3. 不做什么（负范围）

### 3.1 永久不做（已明确排除）

- ❌ 自建 OJ 在线判题（沙箱 + 防作弊 + 判题机，难度极高、收益低）
- ❌ 用 C++ 写后端
- ❌ 获奖积分排名体系
- ❌ 站内短信验证码
- ❌ 微信 / QQ 扫码登录
- ❌ **成绩 / 学分 / 排课 / 学籍** 等学校管理信息系统才有的功能
- ❌ 移动端适配（本期只针对 **1440 / 1920 桌面视口**）

### 3.2 二期再做（P1 一行代码都不写）

- ❌ 在线题库界面与自动判分（**只预留表和字段**）
- ❌ 外链编程题管理界面（洛谷 / 力扣 / 牛客跳转）
- ❌ 作业 / 任务模块
- ❌ 教学视频上传与播放
- ❌ 评论、点赞、成员投稿
- ❌ 错题本、批量导入、请假审批、OJ 自动同步、数据可视化大屏
- ❌ **学习热力图 / 做题排行榜**（2026-10-04 从一期撤销；表保留，二期题库上线后按 [docs/10](10-题库API契约.md) 实现）

### 3.3 硬性红线（永远不可越界）

> 🔄 **修订**：原表述是「任何页面都不得展示成员手机号」，与「管理员需要联系成员」的实际需要冲突。现拆成两条：

- 🚫 手机号**不得出现在任何公开页面** —— 首页、新闻列表/详情、获奖展示墙、排行榜等**游客可见的地方一律不许带**
- ✅ **管理员后台可见**：`/admin/**` 已限定为「指导老师 / 正社长 / 副社长」，成员详情页**可以显示手机号**（这是社长联系成员的实际需要）
- 🚫 **导出的名单仍不含手机号**（这一条**保持不变**）
- 🚫 密码必须 BCrypt 哈希存储，数据库里**不得出现明文**；源码里**不得出现任何明文密码**
- 🚫 获奖对外展示必须**该成员本人同意**

> 🔄 **修订（T-017）**：原文是「组长**只能读写本组数据**」。项目负责人明确改为「**组长只能看，不能改**」，并且**只看得到姓名和人数**：

- 🚫 组长**只能查看本组的组名、组员人数、组员姓名** —— **不能修改任何数据**
- 🚫 组长**不能访问任何 `/admin/**` 后台页面**（成员列表、分组管理…一律 403）
- 🚫 组长**看不到**学号、角色、状态，尤其**看不到**任何人的手机号
- 🚫 副社长**不能**删除数据、**不能**管理账号
- 🚫 数据库密码不得提交到 Git

## 4. 验收标准

> 判定"这个任务做完了"的**唯一依据**。每条都要能实际点一遍、看得见结果。

### 4.1 总体验收（上线前必须全部打勾）

> 📌 本节是【上线前】的统一验收清单，**故意保持未勾选**；其中已实测通过的项见 §4.2 与 [09-开发进度日志](09-开发进度日志.md)。

- [ ] 能创建成员，并用**学号 / 用户名 / 手机号三种方式**都能登录同一账号
- [ ] 数据库里**看不到明文密码**；源码里搜不到任何明文密码
- [ ] 未登录访问 `/admin/**` 自动跳登录页；越权访问返回 403
- [ ] 组长在「**我的小组**」页面里**只看到本组的姓名与人数**；访问 `/admin/**` 一律 **403**；**看不到手机号**
- [ ] 成员能改自己的 **QQ / 微信 / 邮箱**；**改不了**姓名、学号、**手机号**（这三样只能管理员改）与别人的资料
- [ ] ⭐ **签到日历**：到场签到后对应格子染色（**品牌蓝**），可切换年份
- [ ] 新闻能存草稿（**游客直接访问详情 URL 也看不到**）、发布、置顶、分类筛选、显示封面图
- [ ] 游客不登录能看首页、新闻列表、新闻详情
- [ ] **公开页面**扫描确认没有任何手机号（管理员后台详情页可见，见第 3.3 节修订）
- [ ] **获奖**：团队奖只有**同意公开**的人出现在展示墙；**全票不同意的奖整条不出现**、**不展示证书照片**
- [ ] 导出的三个 CSV（考勤表 / 成员名单 / 获奖清单）用 WPS / Excel 能正常打开，且**都不含手机号**
- [ ] **桌面浏览器**（1440 / 1920 视口）能正常浏览与签到
- [ ] 100 人同时在线不崩（简单压测）

### 4.2 分模块验收（每个任务完成后逐条勾）

**T1 账号与登录**
- [ ] 三种登录方式都能进同一账号
- [ ] 密码错误有明确提示，不会 500
- [ ] 禁用账号登录被拒绝
- [ ] ⭐ **忘记密码**：登录页有「忘记密码」入口（**不带附加说明文字、不得出现"重置"二字**）→ 申请页可提交 → 提交后进入**待审核**、此时**旧密码仍然可用** → 社长**审核通过后，新密码生效、旧密码失效** → 社长**拒绝**则旧密码继续有效
- [ ] 忘记密码申请页的 4 个状态都能看到：空闲 / 提交中 / 字段级错误（账号不存在、两次密码不一致、新密码太短）/ 提交成功

**T2 成员档案**
- [ ] 新增成员后能立刻用其学号登录
- [ ] 列表搜索（姓名/学号）能在 1 秒内出结果
- [ ] 按组、按状态筛选结果正确

**T3 分组**
- [ ] 能新建组 / 改组名说明 / 指定组长 / **添加组员** / **删除组**
- [ ] **删除组后，原组员自动变成「未分组」**（不会丢人、不会报外键错）
- [ ] **添加组员时，若他在别的组会从原组移出**，页面提示写明这一点
- [ ] 指定组长后，该组长登录能在「我的小组」看到**本组的姓名与人数**；**访问后台一律 403**

**T4 考勤签到**（= 「你到场了没有」）
- [ ] 成员能看到今天/本周的考勤活动；**到场点一下就签到成功**（`checkin_type=SELF`）
- [ ] **没去就不签** —— 不产生任何记录（不自动补假、不填理由）
- [ ] 同一活动同一人**只有一条**记录（`UNIQUE (event_id, user_id)` 生效）
- [ ] 社长代某成员打卡后，记录里能看到**「由 XX 代打」**（`checkin_type=ADMIN` + `operator_id`）
- [ ] 能看到每人的**出勤率**
- [ ] ⭐ **签到日历**：学员端（`/me`）与 `/me/attendance` **都有**这张图，**只有两种颜色** ——
      **签到了 = 染色（品牌蓝）**，**没签到 = 保持原样（浅灰）**
- [ ] 只能签到**当天**的活动（**当天任意时间都可以**，不限几点）；过去/未来的活动**签不了**
- [ ] 签到后**不能自己取消**（要改找社长代打卡 / 后台修正）
- [ ] ⭐ **连续签到按「例行活动日」算**：这次来了 + 下次也来了 = 连续 2 次；
      **平时来不来不影响连续**；某次没创建活动则跳过不算断
- [ ] 若本周有活动的日子**天天都来**，页面上有一句额外的鼓励文案
- [ ] **导出考勤台账两个独立接口**：`/admin/attendance/export/weekly`、`/admin/attendance/export/all`
      ⚠️ **当前导出的是 CSV（UTF-8 BOM）**
- [ ] 社长层能在 `/admin/attendance` **创建活动**；同一天同类型**不能创建两场**（友好提示，不是 500）
- [ ] 🔒 **组长和学员**访问 `/admin/attendance` 或直接 POST 代打卡 → **一律 403**
- [ ] 🔒 导出权限：正社长 / 副社长 / 指导老师（**组长不行**）；**导出内容不含手机号**

**T5 新闻公告**
- [ ] 草稿状态的新闻游客访问不到
- [ ] 分类筛选、分页正常
- [ ] 上传封面图后，列表和详情都能显示

**T6 公开首页**
- [ ] 不登录可访问
- [ ] ⭐ **首页结构**：Hero（社团名 + 主口号 + 一句简介 + 注册按钮）→ **焦点图轮播** → **左「社团简介」（窄，1/3）/ 右「最新新闻」（宽，2/3）两栏** → 功能卡片 → **「获奖公示」区块（无公开获奖时不渲染）** → 建设进度
- [ ] ⭐ **焦点图轮播**：展示 3–5 张**已发布且对外公开**的新闻封面，**置顶优先**；5 秒自动切换、鼠标悬停暂停；左右箭头与圆点可切换；**点击整张进入该新闻详情**
- [ ] 轮播图**无封面时**显示占位（不是破图）；**一条新闻都没有时**显示默认横幅，不留空白
- [ ] 🔒 **草稿与"仅登录可见"的新闻绝对不上首页**
- [ ] 显示最新 3～5 条已发布新闻
- [ ] 页面里没有任何联系方式

**T7 获奖**
- [ ] 一条团队奖关联 3 人、只有 2 人同意公开 → 展示墙只出现这 2 人
- [ ] **全票不同意的奖整条不出现**；**不展示证书照片**
- [ ] 证书图能在**后台**上传并正常显示
- [ ] 🔒 公开意愿**只有本人**能在 `/me/awards` 打开 / 撤回（后台没有勾选框，管理员不能代表态）

**T9 统计导出**
- [ ] 总览数字与实际数据一致
- [ ] 导出的名单**不含手机号**

### 4.3 非功能验收

- [ ] 普通页面在本机 1 秒内打开
- [ ] 代码有注释，关键逻辑讲得清"为什么这么写"
- [ ] 知道怎么重启服务、怎么看日志
